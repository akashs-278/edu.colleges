Steps to create Database1.accdb and table for Program 8

1) Install Microsoft Access Database Engine (ACE) if you don't have it:
   - For Provider=Microsoft.ACE.OLEDB.12.0 you can install "Microsoft Access Database Engine 2010 Redistributable" (AccessDatabaseEngine.exe) or the 2016 redistributable.
   - Match the bitness (32-bit or 64-bit) to the version of Visual Studio and the application you will run.
   - Download links (examples):
	 - 2010: https://www.microsoft.com/en-us/download/details.aspx?id=13255
	 - 2016: https://www.microsoft.com/en-us/download/details.aspx?id=54920

2) Create the Access database file:
   - Open Microsoft Access (or use an existing tool) and create a new blank database named Database1.accdb.
   - Save the file into the application output folder (for development place it in the project directory so it will be copied to the build folder):
	 Project folder: Program8\ (where Program8.csproj is located)
	 Final location used at runtime: <exe folder> (the app looks for Database1.accdb next to the executable)

3) Create the table and fields:
   - Create a table named DataBase1 with the following fields:
	 - Id (Short Text or Number)
	 - Name (Short Text)
	 - Age (Number or Short Text)
   - Save the table as DataBase1.

4) Copy the Database1.accdb file to the build output folder (bin\Debug\net10.0-windows or bin\Release\net10.0-windows) or keep it in the project folder so it's accessible at runtime.

Notes:
- If you cannot install ACE or prefer to use SQL Server/SQLite, the project code would need to be adapted.
- The project includes code that uses Provider=Microsoft.ACE.OLEDB.12.0 and expects Database1.accdb next to the executable.
- If you need, I can add a script or steps to copy the .accdb into the output folder as a post-build action.
